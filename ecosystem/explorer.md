# Blockchain Explorer

Explorer giúp theo dõi dữ liệu blockchain theo thời gian thực.

## Tính năng

- kiểm tra transaction
- kiểm tra block
- kiểm tra ví
- theo dõi validator

## Explorer URL

```bash
https://scan.simplechain.com
```

## Kiểm tra transaction

Ví dụ:

```bash
https://scan.simplechain.com/tx/0x123...
```

## Kiểm tra block

```bash
https://scan.simplechain.com/block/100
```
