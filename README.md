# Tài liệu SimpleChain

Chào mừng đến với tài liệu chính thức của SimpleChain.

SimpleChain là blockchain tương thích EVM được thiết kế cho các ứng dụng Web3, Smart Contract và hệ sinh thái phi tập trung.

## Tính năng chính

- Tương thích EVM
- Tốc độ giao dịch cao
- Phí gas thấp
- Hệ thống Validator
- Hỗ trợ JSON-RPC API
- Hỗ trợ Smart Contract
