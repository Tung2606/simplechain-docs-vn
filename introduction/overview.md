# Overview

SimpleChain là blockchain tương thích EVM được thiết kế nhằm cung cấp hiệu suất cao, chi phí thấp và khả năng mở rộng mạnh mẽ cho các ứng dụng phi tập trung.

## Main Features

- EVM Compatible
- JSON-RPC API
- WebSocket Support
- Validator System
- Staking Mechanism

## Quick Start

RPC Endpoint:

```bash
https://rpc.simplechain.com
```

Ví dụ request:

```json
{
  "jsonrpc":"2.0",
  "method":"eth_blockNumber",
  "params":[],
  "id":1
}
```
