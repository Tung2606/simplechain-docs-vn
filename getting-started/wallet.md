# Thiết lập ví

Hướng dẫn kết nối ví với mạng SimpleChain.

## Ví được hỗ trợ

SimpleChain hỗ trợ các ví EVM phổ biến:

- MetaMask
- Rabby Wallet
- Trust Wallet

## Thêm mạng vào MetaMask

Mở MetaMask và chọn:

```text
Settings → Networks → Add Network
```

Sau đó nhập thông tin sau:

| Thông tin | Giá trị |
|---|---|
| Network Name | SimpleChain |
| RPC URL | https://rpc.simplechain.com |
| Chain ID | 1337 |
| Currency Symbol | SIM |
| Block Explorer | https://scan.simplechain.com |

## Kiểm tra kết nối

Sau khi thêm mạng thành công:

- ví sẽ hiển thị token SIM
- có thể gửi giao dịch
- có thể kết nối DApp

## Lưu ý bảo mật

- Không chia sẻ Private Key
- Không chia sẻ Seed Phrase
- Chỉ sử dụng RPC chính thức
- Luôn kiểm tra URL website
> ⚠ Không chia sẻ Seed Phrase hoặc Private Key với bất kỳ ai.
